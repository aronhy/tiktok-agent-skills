# TikTok 内容获客报告模板

使用下列固定顺序。正式定制报告必须有完整必填 brief；每个判断在表格中标注其证据类型和 A/B/C 可信度。没有兼容下游数据时，不以公开指标替代私域或成交结果。

## 1. 一句话获客定位

以“为 [客户] 的 [问题/场景]，用 [服务与可验证证明]，引导其 [单一下一步]”写一句话，并标注假设或证据。

## 12. 缺失信息与下一个问题

### 有界缺项例外

若用户明确无法提供必填项仍要求继续，只提供 C 级条件框架：用“若…则…”写出可选路径、未能决定的项目和需要验证的测试。不得填写上述 1–11 节来伪装为正式定制报告，也不得给出无依据的定位、日历、CTA 或 KPI。
